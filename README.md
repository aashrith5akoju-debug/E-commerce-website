# 🛒 E-Commerce Website

A modern full-stack e-commerce website built using **React.js, Vite, and Supabase**.

The application provides a complete shopping experience including user authentication, product browsing, cart management, and order management.

## ✨ Features

- 🔐 User Signup & Login
- 👤 User Authentication
- 🛍️ Product Browsing
- 👕 Category-based Products
- 🔎 Product Search
- 🛒 Add to Cart
- ➕ Increase/Decrease Product Quantity
- ❌ Remove Products from Cart
- 💰 Cart Total Calculation
- 📦 Order Management
- 🗄️ Supabase Database Integration
- 📱 Responsive User Interface
- ⚡ Fast and Modern React UI
